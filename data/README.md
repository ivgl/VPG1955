# Публичные данные национальных механик

Будущие файлы `<country>.json` будут содержать только утверждённые к публикации показатели для интерактивных страниц стран.

Пока отдельные JSON **не созданы**: США использует встроенные демонстрационные значения из `countries/usa.html`.

После утверждения структуры данных в каждый JSON стоит включить как минимум `country_id`, `state_year`, `source_head_id`, `mechanics_version` и публичные показатели. Секретная информация никогда не должна попадать сюда.
