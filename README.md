# ВПИ 1955 — интерактивные национальные механики

Публичный сайт: https://ivgl.github.io/VPG1955/

## Структура

- `index.html` — общий каталог 12 государств.
- `countries/usa.html` — перенесённый прототип интерактивных механик США (начальные демонстрационные показатели 1955 года).
- `css/style.css` — оформление каталога стран.
- `data/` — место для будущих **публичных** JSON-снимков стран после согласования схемы.

Сейчас страница США сохранена с собственными CSS и JavaScript, чтобы не менять её калькуляторы при переносе. По мере утверждения механик интерфейс можно разделить на переиспользуемые компоненты.

## Порядок обновления

1. Обсудить и утвердить правило механики, сохранить каноническую версию вне сайта в Google Drive.
2. Добавить её визуализацию на страницу соответствующей страны.
3. Проверить ссылки, работу калькуляторов и мобильную версию.
4. После утверждённого COMMIT игрового хода выполнить `SITE_SYNC`: опубликовать **только открытые данные**, записать SHA коммита и результат в судейский `TURN_HANDOFF`.

**GitHub Pages — публичный интерфейс, а не источник официального состояния игры.** В репозиторий нельзя помещать тайные планы игроков, закрытые судейские сведения и непубличные данные.
