# SITE_SYNC — единое публичное представление состояния ВПИ 1955

**Статус: технический контракт публичной проекции сайта.** Официальное состояние кампании хранится в отдельном приватном GitHub-репозитории; публичный сайт получает только утверждённые открытые данные. Решения утверждает администратор.

## Принцип

Пост игрока → литературный вердикт + структурированные эффекты с уникальными ID → ОДИН финальный state → проверенная публичная проекция → все страницы GitHub Pages.

Сайт не имеет собственного «судейства механик». Ползунки сценариев меняют только временные предположения пользователя, а не официальный state. После хода меняются публичные данные, а не обязательно 12 HTML-файлов.

## Запись результата непосредственно в вердикте

Каждому решению присваивается decision_id; каждый эффект записывается с effect_id, target, kind, field, before, after, unit, visibility, источниками и статусом утверждения. При применении effect_id обрабатывается один раз; повторный прогон не удваивает бонус или расход.

Вымышленный пример — не реальное игровое действие:

```json
{
  "status": "EXAMPLE_ONLY",
  "decision_id": "FRG-1955-TEST-001",
  "literary_verdict": "Правительство договорилось о финансировании учебных центров.",
  "effects": [
    {
      "effect_id": "FRG-1955-TEST-001:training",
      "visibility": "public",
      "target": "FRG",
      "kind": "process",
      "field": "military.training_system.stage",
      "before": "preparation",
      "after": "initial_schools",
      "unit": "stage",
      "approved": false
    }
  ]
}
```

Общая машинная часть вердикта обновляет официальное поле ровно один раз. Страница Бундесвера выводит состояние этого поля, а не начисляет второе улучшение при публикации.

## Предлагаемые связи экранов с official state

| Экран | Источник факта | Если нет подтверждённых данных |
|---|---|---|
| США, Конгресс | politics.chambers, politics.factions, coalition_deals | Нет подтверждённого числа сторонников, не вычислять голосование |
| США, карта штатов | law.school_desegregation, public_processes по штатам | Сведения требуют уточнения |
| США, европейские базы | world.base_rights, military.deployments, aid_budget | Нет права или его статус не подтверждён |
| СССР, институты | politics.institutional_balance, officials, appointments | Не выдумывать проценты влияния по литературному описанию |
| СССР, Госплан | economy.investment_plan, industrial_capacity и исполненные проекты | Отличать заявку от одобренного вложения |
| СССР, Восточная Европа | world.treaties, bilateral_relations, public_crises | Показать год последнего подтверждения |
| ФРГ, дорожная карта | world.treaties, politics.legal_powers, active_processes | Этап ожидает решения, не автоматически завершён |
| ФРГ, армия | military.training_system, military.units, military.inventory | Нет подтверждения готовности, не считать её нулём без основания |
| ФРГ, промышленность | industry.sectors, labour_supply, trade_demand | Качественный комментарий, а не выдуманный индекс |
| Британия, фунт | fx_1955_usd, exchange_rates, external_trade | Не подменять резервами в INT$ или произвольными G$ |
| Британия, базы | world.base_rights, military.facilities, bilateral_treaties | Не предоставлять бесплатный доступ к базе |
| Британия, программы | fiscal_spending, industry.programmes, active_processes | Подчёркивать разницу плана и фактического исполнения |

Указанные названия — **схема для согласования**, а не гарантия того, что все пути уже существуют в сегодняшнем официальном state.

## Протокол публикации

1. После вердиктов, апелляций и FINAL_APPROVED администратор утверждает новый выпуск в приватном GitHub; изменения фиксируются коммитом, HEAD переключается последним.
2. Из подтверждённого HEAD строится только PUBLIC projection: никаких скрытых планов, разведданных, судейских заметок и неопубликованных NPC решений.
3. Публичный manifest содержит campaign_id, turn_year, source_head_id, rules_version, mechanics_version, timestamp и хеши страновых файлов.
4. Каждый страновой файл должен совпасть с manifest по turn_year и source_head_id. Иначе страница показывает предупреждение об устаревших данных или блокирует обновлённую интерпретацию.
5. В dev-публикации валидируются реестры, единицы валюты и межгосударственные факты; проверенные данные публикуются одним коммитом GitHub.
6. В TURN_HANDOFF пишется SITE_SYNC: PUBLISHED / FAILED_RETRY / SKIPPED_NO_CHANGES, SHA сайта, URL и привязка к официальному HEAD. Ошибка публикации сайта не отменяет утверждённый релиз в приватном GitHub: публичная проекция публикуется повторно из зафиксированного состояния.

## Стоп-условия

- Литературная фраза «влияние министра растёт» не задаёт число 73/100 без утверждённого параметра. Сайт показывает качественную запись.
- Если нет исторически сопоставимого источника и курса, валютные и G$-балансы не суммируются.
- Если действие затрагивает две страны, оно фиксируется в world один раз и читается обеими страницами.
- При смене года сайт не использует молча старый сценарный процент; год и HEAD показываются пользователю.
- Карты, аналитика и интерактивные формы никогда не меняют приватное официальное состояние по одному нажатию.

## Следующий практический тест

После утверждения шаблона создать 2 фиктивных PUBLIC_DEMO HEAD (до/после вымышленного поста), не затрагивая официальный HEAD. Обновить один тренировочный валютный показатель и один статус военно-политического процесса; убедиться, что оба экрана показывают новую запись без правки HTML и что несоответствующий manifest обнаруживается.
