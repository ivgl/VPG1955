# ВПИ — патч RC1.0 от 05.11.2026: формат переговоров

**Статус:** утверждённый административный патч, опубликован на публичной странице правил. Этот файл — готовый текст для публикации в Discord; **сама отправка в Discord не выполнена**.

## Короткое объявление для игроков

> **Патч правил: открытые и закрытые переговоры**
>
> С этого момента в начале каждой **приватной ветки переговоров** стороны обязаны указать формат: **ОТКРЫТЫЕ** или **ЗАКРЫТЫЕ**. **Оба участника должны отдельно подтвердить один и тот же формат сообщениями в начале ветки**, до предметного обсуждения. Если участников больше двух, подтверждают все.
>
> **Открытые переговоры** — сам факт контакта известен в игровом мире, но содержание приватной переписки автоматически не публикуется. **Закрытые переговоры** — факт и содержание не становятся общеизвестными без раскрытия, утечки или игровых действий.
>
> Приватность канала Discord сама по себе не определяет формат переговоров в РП. Если подтверждений нет, формат не установлен; до согласования нельзя считать информацию публичной или гарантированно секретной. Поменять формат можно только новым взаимным подтверждением, без обратной силы.
>
> Для уже идущих переговоров без обозначенного формата согласуйте его перед следующим содержательным этапом. Всё остальное — полномочия, договоры и судейство — действует по RC1.0.

```
Участник 2: «Подтверждаю формат: ...»
```
